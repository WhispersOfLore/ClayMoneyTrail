## Method and limits

Counts contributor names across both loaded campaign-finance cycles plus every entity named in the Evidence Ledger. Does **not** yet include county vendor/contract data, property records, or BCC agenda sponsor data (none of those are loaded in structured form yet — see `RECORDS_NEEDED.md`), so this is necessarily an undercount of true repeat appearances. Names are matched by exact normalized string only — no fuzzy/entity-resolution matching was applied, so e.g. "Isabelle Purvis" and "Coen Purvis" are NOT merged even though they may be the same household (per this investigation's own rule against merging without confirmation).
