# Pattern Matrix — Entity Cross-Reference

Cross-references entities appearing in more than one of: property records,
development applications, campaign contributions, county contracts, BCC
appearances, or infrastructure spending. Per the mission's classification
scheme, every relationship below is one of: **DOCUMENTED DIRECT
RELATIONSHIP**, **DOCUMENTED INDIRECT RELATIONSHIP**, **POSSIBLE MATCH**,
**GEOGRAPHIC COINCIDENCE**, **NAME MATCH ONLY**, or **NO CONNECTION FOUND**.
A relationship existing does not mean it is improper.

**Honest scope note:** ClayMoneyTrail does not yet have vendor/contract or
broad property-records datasets loaded (see `RECORDS_NEEDED.md`), so most
cross-reference cells below are genuinely thin. This matrix reflects that —
it is not padded with speculative connections.

applications, campaign contributions, county contracts, and infrastructure
spending.** The two closest candidates (Fleming Island Chiropractic,
Kronmiller) each appear in exactly two categories (business ownership/
campaign money), both fully explained by Burke's own ownership or a
transparent paid-vendor relationship. This is a genuine finding, not a
placeholder: the pattern-detection goal of this workstream currently
returns "no multi-category pattern found" rather than a hidden connection.
