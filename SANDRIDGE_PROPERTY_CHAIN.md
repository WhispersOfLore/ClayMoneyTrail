# Sandridge Road / Lake Asbury / District 5 Property Chain

Status: early-stage, 2026-09-11. This file tracks the
PROPERTY → OWNER → SALE → BUYER → LLC → DEVELOPMENT APPLICATION → COUNTY
ACTION → VOTE → OUTCOME chain for District 5 growth areas. One parcel has a
complete primary-source chain so far (via the Gustafson investigation
workstream); the Sandridge Road / CR 739B corridor itself — a distinct
geographic area — has an infrastructure project confirmed but no specific
parcel chain built yet. **Do not conflate the two areas**: CR 16-A / The
Springs (below) and Sandridge Road / Lake Asbury are different parts of
District 5.

## Geography note

- **The Springs / CR 16-A corridor** (Green Cove Springs): where the one
  complete parcel chain below sits. Planning district "The Springs."
- **Sandridge Road (CR 739B) / Lake Asbury corridor**: the road-widening
  project and master-plan/moratorium area described in `LEADS.md`
  (LEAD-sandridge). No specific parcel has been traced here yet.
